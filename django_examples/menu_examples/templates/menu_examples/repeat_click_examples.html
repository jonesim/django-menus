Repeat clicks on menu links

Most menu items point at a view that just shows a page, where clicking twice costs nothing. Some point at a view that does something — and a double-click sends that URL twice, so a view which works out what to act on from its own current state acts on both.

The counter below is bumped by exactly that kind of view: it counts every request it is sent, then redirects back here. It also sleeps for a second before answering — the guard drops a click that repeats a navigation already under way, so there has to be a window in which one is. A real server doing real work supplies that; a local runserver answering instantly would close it, and this page would demonstrate nothing.

Try it
  1. Leave the switch off and double-click Bump the counter. The counter goes up by two — the view was reached twice.
  2. Turn the switch on and double-click it again. The counter goes up by one.
  3. With the switch still on, click it once, wait for the page to come back, then click again. It goes up each time — only a repeat of a click that is already navigating is dropped, never a deliberate second one.
  4. Double-click A javascript: item with the switch on. Two alerts: the page never went anywhere, so nothing is held.
Turning it on for real

The switch above is only so you can see both behaviours on one page. A project sets it once, anywhere its own JS runs — a base template is the obvious place: 

{% templatetag openblock %} lib_include module='django_menus.includes' {% templatetag closeblock %}
<script>django_menus_repeat_click_ms = 2000;</script>

Either side of the include works — the value is initialised from window rather than overwritten, and it is read on every click rather than captured at load. That last part is what lets the switch above work without a reload. Set it back to 0 to turn it off; anything that is not a number above zero reads as off.

What it will not do for you

It stops a duplicate click, not a duplicate request. Reload this page after bumping, or press Back and then Forward, and the counter moves again — the guard never sees those. A view that minds being called twice still has to be idempotent; this is the layer in front of that, not a replacement for it.
